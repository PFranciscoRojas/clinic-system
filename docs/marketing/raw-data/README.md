# raw-data — material crudo de la voz del cliente

Aquí van los transcripts sin procesar: entrevistas grabadas, exports de WhatsApp,
sesiones de feedback con profesionales, hilos de grupos del gremio.

## Reglas

1. **El contenido de esta carpeta no se commitea.** Está en `.gitignore`. Contiene
   nombres, teléfonos y correos de profesionales reales, y el repo lo lee cualquier
   agente que corra aquí. Solo se commitea el documento ya minado
   (`../voz-del-cliente-AAAA-MM.md`).
2. **Se guarda el transcript crudo, no el resumen.** El resumen se genera después y
   nunca reemplaza al original. Ver `tareas_clinica.md` como ejemplo de lo contrario.
3. **Nunca entra dato clínico de un paciente.** Ni transcripciones de sesión, ni notas,
   ni nombres de consultantes. El cliente de Chapni es el psicólogo.
4. Nombre de archivo descriptivo con fecha: `entrevista-01-insight-psicologia-2026-09-03.md`.
