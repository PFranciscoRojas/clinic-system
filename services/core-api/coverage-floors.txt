# Coverage floors for core-api, enforced by scripts/check_coverage.sh in CI.
#
# Format: <target> <minimum percent>
#   total          the whole module
#   <import path>  one package
#
# The ratchet only goes up. If a run measures more than DRIFT points above a
# floor, the check fails and tells you the new number to write here: that is
# deliberate, it is what stops the floor from rotting while the code improves.
# If a run measures below a floor, the check fails too — that is a PR adding
# untested code.
#
# Measured with `go test -short`, i.e. unit tests only. The integration suite
# (testcontainers) still runs in the core-api-test job; it is excluded here
# because it exercises SQL through a raw pool rather than Go statements, so
# counting it would inflate the number without reflecting tested logic.
